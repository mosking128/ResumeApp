## 1. 工程目标与范围

在空仓库中实现可本地运行的简历编辑 SPA，覆盖：

1. 多档案存档（增删改查、复制、切换）
2. 模块化拖拽排版
3. 多模板切换
4. 照片上传裁剪
5. 教育/工作/项目的年-月时间选择
6. 可配置间隔的自动保存
7. **A4 页高判定：超出内容区提示加页，否则锁定写入**

**完成定义（产品级）**：桌面 Chrome/Edge 打开 `npm run dev` 后，用户可独立完成「建档案 → 填内容 → 拖版式 → 换模板 → 存照片 → 超页处理 → 自动保存 → 打印」全流程，刷新页面数据仍在。

## 5. Domain 纯函数规格

### 5.1 `dates.ts`

| 函数 | 签名 | 行为 |
|---|---|---|
| `formatMonthYear` | `(m: MonthYear \| null) => string` | `2024.06`；null → `''` |
| `formatDateRange` | `(r: DateRange) => string` | `2022.03 – 至今` |
| `compareMonthYear` | `(a, b) => number` | 负/0/正 |
| `isRangeValid` | `(r: DateRange) => boolean` | isPresent 或 start≤end；start 可空策略：允许只有 end |

### 5.2 `layout.ts`

全部函数 **不可变更新**，操作 `ResumePage[]`：

| 函数 | 说明 |
|---|---|
| `insertSection(pages, pageIndex, sectionId, columnId, index)` | index 越界则末尾插入 |
| `moveSection(pages, sectionId, toPageId, toColumnId, toIndex)` | 先 remove 再 insert，支持跨页 |
| `removeSection(pages, sectionId)` | 从所属页/列删除 |
| `findSectionLocation(pages, sectionId)` | 返回 `{ pageId, columnId, index }` |
| `addPageAfter(pages, pageId, columns)` | 在指定页后插入空页；超过 `MAX_PAGES` 抛错或返回原数组 |
| `removePage(pages, pageId)` | 删除页；至少保留 1 页 |
| `createPageFromTemplate(templateId)` | 按模板生成空列结构 |
| `collapseToSingleColumn(columns)` | 模板切换用 |
| `getSectionIdsInReadingOrder(pages)` | 页序 → 列序 → 列内序 |

常量：`MAX_PAGES = 3`，`MIN_PAGES = 1`。

### 5.2b `pageMeasure.ts`（纯逻辑，可单测）

```ts
export interface PageMeasureInput {
  pageContentHeight: number; // A4.height - paddingTop - paddingBottom
  columnHeights: number[];   // 每列内容实测高度
}

export interface PageMeasureResult {
  usedHeight: number;
  isOverflow: boolean;
  overflowPx: number;
}

export function measurePage(input: PageMeasureInput): PageMeasureResult;
export function isInputLocked(overflow: PageOverflowState): boolean;
```

实测 DOM 放在 feature 层；domain 只做比较与容差（`TOLERANCE_PX = 2`）。

### 5.3 默认文档工厂

```ts
function createDefaultDocument(archiveId: string, templateId: string): ResumeDocument
```

- 内置 sections：basic、objective、education、work、skills（空 payload）
- `pages: [page1]`，page1.columns 按模板 `defaultLayout` 排入
- **禁止**再写顶层 `layout` 字段（迁移后删除）

### 7.2 `editorStore`

```ts
interface EditorState {
  doc: ResumeDocument | null;
  selectedSectionId: string | null;
  dirty: boolean;
  saveState: 'idle' | 'dirty' | 'saving' | 'error';
  canvasScale: number; // 0.75–1.25

  /** A4 页高检测（不入库） */
  pageHeights: Record<string, number>; // pageId → usedHeight
  overflow: PageOverflowState;
  /** contentBox 来自当前模板 */
  pageContentHeight: number;

  open(doc: ResumeDocument): void;
  close(): void;
  select(id: string | null): void;
  setTemplate(templateId: string): void;

  addSection(type: SectionType, pageId: string, columnId: string, index?: number): void;
  removeSection(sectionId: string): void;
  moveSection(sectionId: string, pageId: string, columnId: string, index: number): void;
  patchSection(sectionId: string, patch: Partial<Section>): void;
  addSectionItem(sectionId: string): void;
  updateSectionItem(sectionId: string, itemId: string, patch: object): void;
  removeSectionItem(sectionId: string, itemId: string): void;

  setPhoto(blobId: string, meta: ResumeDocument['photoMeta']): void;
  clearPhoto(): void;

  /** 画布 ResizeObserver 回调 */
  reportPageHeight(pageId: string, usedHeight: number): void;
  /** 用户在模态中确认加页 */
  confirmAddPage(): void;
  /** 用户取消 → 锁定写入 */
  cancelAddPage(): void;
  /** 手动「加一页」（未溢出时也可加，若 < MAX_PAGES） */
  addPageManually(): void;

  markSaving(): void;
  markSaved(): void;
  markError(message: string): void;
  markDirty(): void;
  getSavePayload(): ResumeDocument | null;
}
```

#### `reportPageHeight` 逻辑

1. 写入 `pageHeights[pageId]`
2. `measurePage({ pageContentHeight, columnHeights })` — 简化：整页取 `max(列高)` 或预设「单列总高 / 双列各自超高」策略，与画布实现一致
3. 若 `isOverflow`：
   - 更新 `overflow = { overflowingPageId, overflowPx, inputLocked: true, pendingAddPageAfterId }`
4. 若曾溢出且现回落：
   - 清空 `overflow`，`inputLocked = false`，关闭模态

#### `confirmAddPage` / `cancelAddPage`

- 确认：`addPageAfter` → 清 overflow → unlock → markDirty
- 取消：保留 `inputLocked: true`，关闭 UI 模态，底栏警示条常驻

#### 写入锁在 Store 层的强制点

所有会 **增大内容** 的 action 入口检查 `overflow.inputLocked`：

- `patchSection`（文本增长由 Form 提交；Form 侧也要 readOnly）
- `addSectionItem`
- `addSection`
- 若 locked → no-op + 可选 toast「请先加页或删减内容」

允许：`removeSection` / `removeSectionItem` / 删除字符类 `patch`（变短）。

> 实现提示：文本 patch 难以在 store 判断「变长」，V1 以 **UI readOnly** 为主闸，store 只拦「新增 item / 新增 section」。
```

所有变更路径内部统一：`apply(nextDoc)` → `updatedAt = Date.now()` → `dirty = true`。

## 8. Autosave 规格

### 8.1 Hook：`useAutosave()`

挂载于 `App`：

- 订阅 `editorStore` 的 `dirty` / `saveState` / doc 引用
- `settingsStore.settings.autosaveIntervalMs`
- 使用 `setTimeout` 防抖；`dirty && interval` 时启动

### 8.2 强制 flush 场景

| 场景 | 行为 |
|---|---|
| 顶栏「保存」按钮 | flush + 状态反馈 |
| 切换档案 | 先 flush，失败则 confirm 阻止 |
| 删除当前档案 | 先取消定时器再删 |
| `beforeunload`（若 dirty） | `event.preventDefault()` 提示（浏览器限制下尽力） |
| `visibilitychange` → hidden | async flush |

### 8.3 状态 UI

顶栏文案：

- `未打开文档`
- `所有更改已保存 · 14:02`
- `正在保存…`
- `保存失败 · 重试`
- 自动保存关闭时：`自动保存已关闭`

## 9. 功能模块实现要点

### 9.1 档案管理（`features/archive-manager`）

- 顶栏下拉：列表按 `updatedAt` 降序
- 操作：新建、重命名（inline 输入）、复制、删除（confirm）
- 空态：引导「创建第一份简历」并直接 `create()`

### 9.2 模块库（`features/module-palette`）

- 列出 registry 中非 singleton 或「singleton 未添加」的模块
- `useDraggable`；`disabled` 时说明原因（如「个人信息已存在」）
- 点击也可「添加到主栏末尾」（无鼠标拖拽用户）

### 9.3 画布（`features/editor-canvas`）

- 外层滚动容器纵向排列多页
- 每页：`width: 794px; height: 1123px; overflow: hidden` + `transform: scale(canvasScale)`
- 页内容区：按模板 `contentBox` padding；**测量容器不缩放干扰**——测量用 `offsetHeight`/`getBoundingClientRect` 时换算 scale，或测量未 transform 的内部节点
- 每列 `Droppable`；每 section `Sortable` + grip
- 点击 section → `select(id)`
- 删除按钮（标题栏右侧，hover 显示）
- 空列：虚线占位「拖入模块」
- 页脚标签：`第 n 页`；溢出页琥珀色

#### 高度上报

```
每个 page 根节点:
  ResizeObserver → 读各列 scrollHeight/offsetHeight
  → reportPageHeight(pageId, usedHeight)
```

- `usedHeight`：双栏取 `max(左列内容高, 右列内容高)`；单栏取唯一列
- 节流：与编辑防抖合并，**≥120ms** 一次
- section 增删/字号变化/换模板后强制重测

#### A4 常量

```ts
// domain/types.ts
A4 = { width: 794, height: 1123 }
```

模板补充字段：

```ts
contentBox: { paddingTop: number; paddingBottom: number; paddingLeft: number; paddingRight: number }
```

`pageContentHeight = A4.height - paddingTop - paddingBottom`。

### 9.3b 页溢出闸门（`features/page-overflow`）

#### 组件

| 组件 | 职责 |
|---|---|
| `PageOverflowModal` | 居中模态：说明 +「加一页」/「取消」 |
| `OverflowBanner` | 画布底栏常驻警示：`第 N 页已超出 X px` + 快捷「加一页」 |
| `useInputLock()` | 返回 `locked`，供 TextField/TextArea/Palette 使用 |

#### 模态行为

- 触发：`overflow.overflowingPageId !== null && !userDismissedModal`
  - V1：溢出即 `open`；用户取消后仅 banner，不再自动弹（直到再次从「未溢出→溢出」）
- 「加一页」：`confirmAddPage()`；若 `pages.length >= MAX_PAGES` 按钮 disabled
- 「取消」：`cancelAddPage()`
- `role="dialog"` + 焦点陷阱 + Esc = 取消

#### 写入锁 UI

| 控件 | locked 时 |
|---|---|
| TextArea / TextField | `readOnly`，光标仍可选中复制 |
| 「添加一条」按钮 | disabled |
| 模块库拖入该溢出页 | drop 禁止 |
| 删除 / 剪短文本 | 允许 |
| 拖模块到未溢出页 | 允许 |

文案见框架设计 §6.5。

### 9.4 属性面板（`features/property-panel`）

- 无选中：显示文档级操作（模板说明、档案信息、页数、溢出快捷入口）
- 有选中：挂载对应 `ModuleDefinition.Editor`
- 列表型模块：每条 item 折叠卡 + 「添加一条」（locked 时 disable）
- 底部：上移/下移/移除模块

### 9.5 日期字段（`features/date-range-field`）

```tsx
<DateRangeField
  value={item.date}
  onChange={(date) => updateSectionItem(...)}
  allowPresent
/>
```

交互：
- 两个触发器「开始」「结束」
- 弹出层：年 `select` + 月 3×4 网格
- 「至今」checkbox 置灰结束月年
- 非法区间时字段边框 warn

### 9.6 照片裁剪（`features/photo-cropper`）

```tsx
<PhotoCropper
  open={boolean}
  sourceUrl={string}
  aspect={1 | 0.75}
  onCancel={() => {}}
  onConfirm={(blob: Blob, meta) => {}}
/>
```

实现要点：
- 遮罩层内预览区正方形或 3:4
- 滚轮/滑杆缩放，拖拽平移（限制边界）
- 确认时：按预览区映射回原图像素 → `canvas` → `toBlob`
- basic 预览与打印均用导出后的 blob（所见即所得）

### 9.7 模板切换（`features/template-switcher`）

- 下拉或分段控件展示 3 模板缩略名
- `setTemplate`：
  1. 更新 `doc.templateId`
  2. single：`collapseToSingleColumn`
  3. 双栏：按类型启发式分列（basic+summary+skills+objective → 侧栏；education/work/project → 主栏），**保留用户 section 创建顺序**
- Toast：「已切换模板：经典单栏」

### 9.8 打印 / 导出（`features/export-print`）

- `print.css`：隐藏 shell chrome，**按 `pages[]` 顺序输出多张 A4**
- 每页：`width: 210mm; height: 297mm; page-break-after: always`（最后一页除外）
- `@page { size: A4; margin: 0 }`（页边距由模板 `contentBox` 控制）
- 顶栏按钮 `window.print()`
- 文档说明：弹出系统对话框选「另存为 PDF」
- 打印前若仍 `inputLocked`：Toast 提醒「内容超出 A4，建议先加页或删减」，仍允许打印（用户负责）

| `TextField` / `TextArea` | 表单；支持 `readOnly`（写入锁） |
| `Modal` | 裁剪、确认删除、**溢出加页** |
| `Toast` | 保存失败、模板已切换、写入锁提示 |
| `EmptyState` | 无档案、空列、空第二页 |
| `Select` | 档案、模板、年份 |
| `PageFrame` | 单页 A4 外壳 + 页码 |

### 10.2 无障碍底线

- 所有交互元素可 Tab 聚焦，`focus-visible` 环（accent 2px）
- 图标按钮有 `aria-label`
- 拖拽提供键盘按钮替代（上移/下移/移除）
- 正文对比度 ≥ 4.5:1
- 溢出模态可键盘确认/取消；写入锁时输入框 `aria-readonly`
- `prefers-reduced-motion`：关闭非必要过渡

## 14. 错误处理约定

| 场景 | 用户可见行为 |
|---|---|
| IndexedDB 打开失败 | 全屏错误页：说明浏览器需支持本地存储/隐私模式限制 |
| 写盘失败 | 状态栏 error + 重试；Toast 一次 |
| 图片过大/非图片 | 裁剪前校验，Toast「请选择不超过 5MB 的图片」 |
| 档案不存在（脏 id） | 回落到列表第一个或空态 |
| 迁移失败 | 明确报错，不静默清空；可导出 raw JSON（M6 可加） |
| **A4 溢出弹窗** | 「内容超出第 N 页」/「是否新增一页继续编辑？不加页则无法继续写入，可先删减内容。」 |
| **已达页数上限** | 「已达到最大 3 页，请删减内容后再编辑。」（加一页按钮 disabled） |
| **locked 时新增条目** | Toast「请先加页或删减内容」；按钮 disabled |
| **打印时仍溢出** | Toast 提醒后仍允许 `window.print()` |

禁止：静默吞错、失败时 `localStorage` 悄悄丢数据。
